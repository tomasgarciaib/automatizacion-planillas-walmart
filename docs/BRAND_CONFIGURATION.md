# Configuración por marca

Cada marca tendrá un archivo de configuración independiente. Esto evita cambiar el código principal cuando llegue una planilla distinta.

Antes de configurar una marca se deben confirmar:

1. Nombre de cada hoja relevante de la fuente.
2. Columna que identifica el producto y columna que agrupa sus variantes.
3. Campos de origen para cada columna de la plantilla Walmart.
4. Valores fijos y reglas aprobadas por el equipo.
5. Fila inicial de datos de la plantilla y hojas que deben preservarse.
6. Reglas de nombres de archivo y carpeta de destino en Drive.

No se debe activar una configuración solo con una suposición. Se valida contra una planilla ya aceptada por Walmart.
